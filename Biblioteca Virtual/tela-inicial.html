Sobre o projeto

Este projeto é uma biblioteca virtual que permite aos usuários explorar uma coleção de livros, visualizar informações detalhadas sobre cada livro e participar de sorteios para descobrir novas leituras.

Desenvolvido com HTML, CSS e JavaScript, o projeto visa proporcionar uma experiência interativa e agradável para os amantes da leitura e poder aprender mais sobre esse mundo do desenvolvimento web.
