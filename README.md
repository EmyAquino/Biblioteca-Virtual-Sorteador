# Biblioteca Virtual

O projeto "Biblioteca Virtual" foi desenvolvido por mim, como forma de aprendizado e para utilização. A intenção com esse projeto é poder utilizar de forma diária mas neste primeiro momento o projeto é só um protótipo.

## Quais serão as funcionalidades?
- Listagem dos livros (título, autor e ano);
- Sorteio da próxima leitura;
- Resenha do livro.

A ideia principal é ir colocando os livros por Java Script mas com certeza irá ter melhoras durante a criação do projeto

Dentro da pasta "Biblioteca Virtual", irá conter três páginas:
- Html
- CSS
- Java Script
